# Static preview (temporary)

Standalone HTML snapshots of the Shelf frontend, captured from the running app
on labelled demo data — real rendered pages with CSS and fonts inlined, no
server needed. For viewing via raw.githack.com only; live search and other
backend-backed actions do not function here. The real app (Next.js + Fastify +
PostgreSQL) is the rest of this repository and needs a Node host to run.

Entry point: index.html. This folder is a throwaway preview and can be removed
in one commit.
